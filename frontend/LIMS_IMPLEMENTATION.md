# 完整 LIMS 前端扩展记录

## 本轮范围

沿用概念设计的七个主分组，新增采样与统计；客户门户按最终要求交由独立项目，本项目没有门户菜单或客户登录页面。

实现方式为“模板公共组件 + 业务模块声明 + 领域规则 + 事务仓储”。统一表格和详情复用于多模块，但委托、检测、报告、财务、库存等动作有各自的服务层校验和关联写入，不是静态菜单占位。

## 业务映射

| 概念设计入口 | 本项目位置与行为 |
| --- | --- |
| 合同登记、合同评审 | 委托管理 / 合同登记与评审；草稿提交后在审批工作台处理 |
| 委托登记、查询、更改、作废 | 委托管理 / 委托登记与查询；详情按当前状态展示动作 |
| 样品入库、出库、处置、流转查询 | 样品管理 / 样品流转；样品详情展示完整关联链 |
| 检测样品领取、数据录入、数据更改 | 检测管理 / 检测任务与原始记录；领取与样品出库同一笔记录 |
| 复制样品数据 | 检测任务 / 复制记录结构；只复制任务配置，不复制结果、原始读数、签名和审批 |
| 检毕样品处理 | 任务详情 / 检毕样品归还；留样、分样和处置在样品流转办理 |
| 报告审核、批准、打印、查询、归档 | 报告管理 / 报告编制与查询；详情动作和审批工作台处理 |
| 报告内部、外部更改申请 | 报告更改申请 / 申请来源字段；批准产生新草稿并标记原版被替代 |
| 计价调整 | 财务管理 / 计价规则与调整，报价与委托按生效价格生成快照 |
| 设备管理计划 | 质量体系 / 设备计划与执行；计划类型包含周期检定、校准、期间核查、维护和维修 |
| 易耗品、标准物质 | 试剂耗材与标准物质；按批次、库存、单位、成本、有效期、证书管理 |
| 认可能力 | 认可能力管理；关联检测场所、项目、方法、范围版本和有效期 |
| 文件、标准 | 受控文件与检测标准；区分文件类型，批准、发布、生效及作废 |
| 用户、授权、操作日志 | 系统管理 / 用户与角色、授权日志、操作日志 |

质量事项统一承担质控异常、不符合项、投诉、内部审核、管理评审和风险改进；通过类别筛选区分事项。每项具备责任人分派、处理说明、独立验证和关闭，不使用互不关联的重复台账。

## 数据与规则

- 一次 IndexedDB 事务提交业务、关联单据与审计。服务抛错、空间不足或版本冲突不提交状态。
- 委托受理冻结项目、方法、客户与价格快照并生成应收。更改保留历史快照。
- 采样交接创建待接收样品并关联委托；重复交接被状态校验拒绝。
- 已接收样品登记信息只读；实物流转独立。分样生成新编号，关联原委托并扣减原样数量。
- 检测开始检查有效能力授权、方法、设备、期间核查、物料有效期与库存；领样和扣料同事务。
- 原始记录字段与明细列来自方法配置；使用白名单算术解析器，支持定量和定性。质控失败不能提交结果复核。
- 已批准数据不可覆盖；复测/更正创建关联任务，旧结果仍可追溯。
- 预置审批角色可通过指定审批人配置覆盖；实例固定审批名单与配置版本。管理员也不能自审。
- 报告签发先完成校验与 PDF 生成，再原子保存签发状态、内容快照和 PDF Blob；生成期间数据变更会拒绝提交并要求重试。
- PDF 页面由冻结内容与模板配置生成，中文字体本地嵌入，支持重复表头与页码。归档后下载直接读取同一文件。
- 金额使用整数分结算。收款和退款保留原记录，更新应收状态。技术签发与结算发放分离。
- 完整备份包含 Blob 附件，恢复检查格式、账号、样品和引用关联。恢复不改变主题偏好。

## 模板与依赖

Bootstrap 仍为 5.3.8。没有修改 docs 原模板，没有新增业务样式。

原模板 Flatpickr、中文语言包和 Choices 脚本原样复制。Poppins 字体导入仅做本地 URL 映射，字体声明不做视觉更改；本地 Noto Sans CJK SC 用于 PDF。许可证在 public/fonts。

水平布局使用原模板 More 分组和 dropdown-custom-right，菜单不会一次铺开全部模块。pdfmake 按需加载，较大体积只在首次签发/生成报告时加载。

## 验证

自动验证包括：类型检查、单元测试、全部模块浏览器打开检查、委托到 PDF 下载闭环、角色隔离、样品旧流程、主题布局、模板一致性、生产子目录运行。

额外规则测试覆盖：自审、审批名单冻结、失效设备/授权/物料、库存不足、质控失败、复制记录不带结果、现场采样交接、信用额度与逾期、部分退款、存储失败、旧版 65 条样品迁移、多写入事务串行化和附件 Blob。

## 后续后端接入

替换异步领域服务或仓储适配器，保持 UI 与业务动作边界。真实账号认证、服务端权限、数据库唯一约束、文件存储和不可篡改审计由后端实现；浏览器演示身份不提供生产安全隔离。

本期不包含客户门户、真实税务开票/支付、仪器自动采集、外部通知、电子签章、自由流程设计器或行业专用计算。开票是登记；签发是模拟岗位审批；默认检测方法是演示数据。

本轮验收结果：37 项单元测试、19 项浏览器测试全部通过；类型检查、生产构建、样式源校验与 /lims/ 子目录生产运行通过。桌面工作台、深色双列及手机业务表单已进行截图检查。
