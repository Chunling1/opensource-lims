## 明确不属于首期完整迁移的功能

- 多语言切换、旗帜和翻译字典：当前仅中文，未迁入语言切换。
- 购物车、结算、钱包余额、第三方 Web Apps 外链：没有迁移；快捷应用已改为 LIMS 路由。
- 个人资料页及编辑、账号设置页：当前仅演示资料弹窗和主题设置入口。
- 消息/聊天系统：当前仅“尚未接入”说明，没有真实消息收发。
- 登录、锁屏、退出和权限控制：未实现，菜单已禁用标注；与首期排除登录权限一致。
- 原模板的电商、CRM、邮件、日历、项目、看板、文件管理、图表、完整组件展示页等：未整体迁移。模板 src 根目录有 193 个 HTML 页面，当前仅实现 LIMS 工作台、样品页面和少量组件验证页。
- 样品删除、批量操作、附件、导入导出、检测执行及报告：首期计划已明确排除，不能算作本次模板迁移遗漏。
- 模板购买入口、厂商品牌页脚：已改为关闭设置和 LIMS 页脚，属于有意替换。

## 已确认迁移的主要部分

- 原模板 Bootstrap / app / custom SCSS 编译入口、字体图标及图片资源，Bootstrap CSS/JS 版本统一为 5.3.8；没有新增业务 CSS。
- 11 种主题及本地预览图片、4 种布局、53 个设置控件的原始结构与 class；偏好存储和重置。
- 顶部/侧栏真实头像图片、用户下拉的主要结构、快捷入口、全屏、明暗按钮、手机搜索。
- Hash 路由、导航高亮、移动菜单、样品登记/修改/退回/重新提交/接收、筛选分页及本地持久化。

以上已实现项仍受本报告列出的具体差异限制。已有测试主要证明当前 LIMS 功能可用，并未对 193 个模板页面逐一做视觉对比。

## 建议处理顺序

1. 先修正四个已复现的问题，并为状态联动补上回归验证。
2. 补公共框架效果：返回顶部、滚动阴影、悬浮入口、滚动条、菜单固定/动画/长菜单行为。
3. 按“与模板一致”的验收目标补搜索建议、日期/选择器、通知结构及必要公共插件；业务内容继续使用真实 LIMS 数据。
4. 账号、多语言和模板其他业务模块另行确定范围，避免为还原视觉引入虚假功能。
