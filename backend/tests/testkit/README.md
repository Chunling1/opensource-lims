# Backend module testkit

This package is the shared starting point for new module tests. It creates an
empty SQLite database and a private attachment directory under pytest's
`tmp_path`; it does not seed production/demo records and disables ELN, AI,
BIM/CAD and external side effects.

Opt in from a test module:

```python
pytest_plugins = ("testkit.fixtures",)
```

Available fixtures:

- `isolated_app`: Flask app with an empty schema.
- `isolated_client`: test client for that app.
- `scenario_factory`: virtual department, permission, project, project-step
  and user factory that keeps user grants within the department grant ceiling.

Typical setup:

```python
def test_query_scope(isolated_app, isolated_client, scenario_factory):
    scenario = scenario_factory.identity_scenario(
        permission_codes=("report.query.view",),
        granted_step_codes=("report_review",),
    )
```

All names and records generated by the factory are explicitly virtual. Tests
must not point `SQLALCHEMY_DATABASE_URI` or `STORAGE_ROOT` at a production,
Demo or verification environment.
