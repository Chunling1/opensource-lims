# 范围与后续方向

这是当前实现边界和讨论方向，不是发布时间承诺，也不是新业务规则的批准记录。

## 已有代码

- 我的待办与列表筛选、分页。
- 检测样品领取、责任交接和冻结提示。
- 报告编制、PDF 文件管理、日期核查及提交审核。
- 后端权限核查、并发版本检查、动作记录。
- SQLite 本机试用与 PostgreSQL 测试支持。

## 近期维护方向（建议，尚未排期）

- 完成 Tabler 页面视觉对照和移动端交互检查。
- 扩展弹窗、日期筛选、分页等浏览器回归。
- 排查测试文件句柄警告。
- 改善新环境启动体验和文档一致性。

## 后续业务范围（待设计与确认）

完整委托/收样维护、实际审核批准、签章发放、导出、备份恢复等仍未交付。人员授权、模板、文件存储和集成方案需结合产品决策继续设计，不因为在此列出就承诺全部进入免费版。

## 未定事项

全局搜索范围、主题变量的允许边界、部分界面用语及正式产品名称仍待决定。任何变更应记录依据，不以实现便利替代业务责任和证据要求。
